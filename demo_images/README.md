# Disease sample images

One sample image is included for each of the 10 disease labels currently targeted by Smart Crop Disease Detection. These are example/test images, not a complete training dataset and not a guarantee of field performance.

## Source and attribution

Images are sampled from the PlantVillage-Dataset repository by spMohanty et al.: https://github.com/spMohanty/PlantVillage-Dataset (original PlantVillage dataset paper: https://arxiv.org/abs/1511.08060). See `SOURCES.json` for each original image URL and source class. Keep the upstream attribution and license terms with any redistribution.

## Important

PlantVillage images are generally captured in controlled conditions. Use field photos from Maharashtra for additional evaluation; do not treat these ten examples as a validation set or as evidence of model accuracy.
